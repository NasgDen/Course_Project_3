# Курсовой проект 2 - Работа с базой данных PostgreSQL

## Описание

Данный проект - это консольное приложение написанное на языке программирования Python. Приложение взаимодействует с сайтом HeadHunter (hh.ru) по средствам механизма API.
API — это механизм, который позволяет различным программам взаимодействовать друг с другом, используя набор определенных правил. 
Приложение по заданному поисковому запросу получает список данные о компания и их вакансиях с api.hh.ru и сохраняет данные в базу данных.

## Описание функций
1. Модуль utils.py - Содержит функции для работы c api.hh.ru приложения.
* get_company_api - Функция подключается к api.hh.ru и получение списка компаний.
* get_vacancies_api - Функция получает вакансии по id компании с api.hh.ru.
* config_parser - Функция для чтения конфигурации базы данных из файла и сохранения в словарь.
2. base_database.py - Базовый абстрактный класс BaseDatabase, определяющий интерфейс для создания базы данных и таблиц в ней.
3. db_manager.py - Класс DbManager для работы с таблицами базы данных.
* create_database - Метод создания базы данных.
* create_table - Метод создания таблиц в базе данных.
* insert_companies - Метод заполняет таблице company значениями полученными из api.hh.ru.
* insert_vacancies - Метод заполняет таблице vacancy значениями полученными из api.hh.ru.
* get_company_id - Метод сохраняет значения параметров company_id и vacancies_url в кортеж для нахождение вакансий.
* get_companies_and_vacancies_count - Метод получает список всех компаний и количество вакансий у каждой компании.
* get_all_vacancies - Метод получает список всех вакансий с указанием названия компании, названия вакансии и зарплаты и ссылки на вакансию.
* get_avg_salary - Метод получает среднюю зарплату по вакансиям.
* get_vacancies_with_higher_salary - Метод получает список всех вакансий, у которых зарплата выше средней по всем вакансиям.
* get_vacancies_with_keyword - Метод получает список всех вакансий, в названии которых содержатся переданные в метод слова.

## Установка

1. Клонируйте репозиторий:
```
git clone https://github.com/NasgDen/course-project_3
```
2. В PyCharm установите менеджер проекта poetry.
3. В PyCharm устанавливаем все зависимости проекта из файла pyproject.toml
4. Переименуйте файл database_env.ini в database.ini и измените в нем параметры для подключения к базе данных PostgreSQL.

## Использование:

1. Запустите файл main.py из корневой директории проекта.
2. Введите данные.
3. Просмотрите результат выполнения программы.
